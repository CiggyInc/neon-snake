# Neon Snake — V5 Release Edition

Neon Snake is a polished neon-styled arcade snake game developed by Neon Inc.

This project combines classic arcade snake gameplay with modern features including:

- 🎮 Classic Mode and Free Aim Mode
- 👑 Boss battles and Ascended Mode
- 🏆 Achievement system
- 🎨 Unlockable skins, trails, and themes
- 📊 XP and progression system
- ✨ Smooth animations and neon visual effects
- ⚙️ Customizable settings
- 🌗 Light and dark themes

Built using pure HTML, CSS, and JavaScript — no external frameworks.

---

## 🎯 Vision

Neon Snake is designed as a stylish, replayable indie arcade experience.
The goal is to combine classic mechanics with modern polish and progression systems.

---

## 🛠 Technology

- HTML5 Canvas
- Vanilla JavaScript
- CSS animations
- LocalStorage persistence
